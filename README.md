# Support My Work

A responsive, no-build static website with two support options:
- India: UPI ID, QR image, and a button to open a UPI app.
- International: Buy Me a Coffee link.

## Personalize it

Open `index.html` and edit the `CONFIG` object near the bottom:

```js
const CONFIG = {
  upiId: "YOUR-UPI-ID@BANK",
  payeeName: "Your Name",
  qrImage: "upi-qr.png",
  buyMeACoffeeUrl: "https://buymeacoffee.com/YOUR_PAGE",
  githubUrl: "https://github.com/YOUR_USERNAME"
};
```

Place your UPI QR image in the same folder as `index.html`, named `upi-qr.png` (or update `qrImage` to match the filename). Use a QR code generated by your trusted UPI app, and verify it with a small test payment before publishing. Avoid using a QR with a fixed amount if you want supporters to choose the amount themselves.

## Preview locally

Open `index.html` in your browser. The copy-to-clipboard feature works best on HTTPS or localhost.

## Publish with GitHub Pages

1. Create a new GitHub repository, e.g. `support-my-work`.
2. Upload `index.html`, `README.md`, and your QR image.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for the Pages deployment to finish; GitHub will show the published URL in Settings → Pages.

## Safety

- Never put your UPI PIN, OTP, bank password, or other secrets in this site.
- A UPI ID and payment QR are intended for receiving payments; never approve a collect request you didn't initiate.
- The international link is a placeholder until you replace it with your real creator page.
